# Native gameplay checklist — 1.22.7

**Status:** dedicated-server load/start/stop and fail-open configuration smoke were exercised; connected-client gameplay below is **not yet exercised**. Use a disposable world/backup and an unmodified vanilla comparison server with identical settings. Server-only mod; clients should connect without it. Record coordinates, calendar date/latitude, measured sunlight and block light, local stability, variants and exact distances.

1. **Acquisition boundaries:** idle drifter, shiver, bowtorn; stable open surface, daytime, survival player at 7.99, exactly 8, 8.01 and 12 blocks. At/under 8 native wall/sneak/visibility checks still apply. Beyond 8 only new acquisition is capped.
2. **Pair-specific pursuit:** acquire at 7 blocks; retreat beyond 8. Native pursuit/attacks/forgetting continue. While chasing player A, place B beyond 8: A's pursuit must not exempt B. Allow native chase to end; no permanent aggro flag should remain. Repeat across seek + melee/ranged task handoffs.
3. **Retaliation:** from outside 8, hit an idle monster with melee where practical, an arrow and a thrown projectile. Native reaction must occur without moving into 8. Verify the attacker, not an unrelated observer, gets the exemption; native retaliation expiration still applies.
4. **Both endpoints/shadow:** player fully sunlit, monster deep shade with sunlight <12, same altitude, >8 apart: vanilla acquisition. Reverse endpoints. In ordinary shade with actual sunlight >=12 both can still meet the safe gate. Moving one block across the boundary invalidates its cache immediately; same-block light changes can take 500 ms.
5. **Caves:** both underground, player underground/monster surface, and reverse, including brightly torchlit caves, cave entrances and an overhang. Native terrain height and sunlight must reject safe status; do not assume torches mean sunlight. An excavated open pit can conservatively retain vanilla due generated terrain reference.
6. **Time/season:** winter/summer and different latitudes at dawn/dusk. With seasonal enabled, actual native sun elevation controls the gate even outside 09–19; no fixed-hour fallback. With seasonal disabled, test just before 9, at9, just before19 and at19. Night should be vanilla under defaults.
7. **Temporal environment:** storm activation while safe cache entries exist must immediately bypass cap; local unstable area bypasses at either endpoint. After storm/stability recovery, old unsafe entries may remain for TTL before the cap resumes. Temporal setting/custom generators with unavailable data must leave vanilla.
8. **Distances/dimensions:** verify a >8 vertical gap caps in 3D mode but is within cap in horizontal mode (vanilla still decides). Other dimensions remain vanilla; same ID moved to another block/dimension must not reuse evidence.
9. **Exclusions:** wolves, bears, animals, bosses/special drifters, creative/spectator/dead players and non-player targets remain native. Test entity-list overrides deliberately; exclusions win.
10. **Scheduling/performance:** with native profiler, compare identical monster/player counts and world conditions; no mod entity loop or refresh tick should exist. Count searches/path calls at native methods without changing their cadence. This mod must add zero calls; rejected targets can reduce downstream calls. Do not interpret an identical exact gameplay path count as a requirement when AI behavior has intentionally changed.
11. **Configuration:** stop server, edit defaults, restart. Disable mod via `Enabled:false`; then test malformed JSON, null, duplicate/unknown property and negative range. Original bytes must remain; startup diagnostic must say vanilla unchanged. Restore valid config/restart and confirm enabled log.
12. **Compatibility/restore:** remove ZIP, restart and verify vanilla. Unsupported game version must not install patches. With AI-overhauling mods, failure or replaced acquisition seams can make the cap unavailable; prefer vanilla over broad sensing/pathfinding patches.
